Golden rules
  • One tester per browser profile — the run is saved locally, it does not sync between people.
  • A FAIL needs a note: what you did, what you expected, what actually happened, and a screenshot in the tracker.
  • WhatsApp OTP and order messages only fire when Configuration → WhatsApp → Enabled is on. With it off, the OTP is written to the API log — check with the team, or use the testOtp value in Configuration on a staging box.
  • Don't run npm run seed against a box that already has real vendors or orders — it wipes every data table.
  • The S# refs point at a matching item in QA_PUNCHLIST.md (1–37) or QA_PUNCHLIST_ROUND2.md (38–60).
